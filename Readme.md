This is a simple program designed to take a step model input and output the volume at incremental steps into a CSV file.

Run with python main.py [step_file] [--increment-mm 0.1] [--output-csv out.csv] [--height-axis xyz]
Defaults: increment 0.1 mm, height axis z

Note that you must have FreeCAD installed and in your PATH to be usable by python.
Note that all units are in millimeters.
